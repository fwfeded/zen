## 为什么做禅

> 手机已经慢慢成为大部分人——包括我自己——的第二故乡。每天冒出来的大量信息，越装越多的应用，却也在不断夺走我的注意力和时间。所以，我想开发这个第二桌面，帮我把自己的时间和注意力抢回来。

很多时候，拿起手机本来有一个很小、很明确的目的：查一份资料、回复一条消息，或记下刚想到的事。可解锁之后，图标、通知和内容不断出现；等回过神，最初想做的事反而还没有开始。

禅从这个日常困扰出发，重新安排桌面上“什么先出现、什么在需要时出现”。少量必要应用留在手边，其他应用由你主动搜索；专注、待办、统计和设置收在清晰的入口里。手机依然能做原来的事，而打开手机之后的下一步，希望更多由你来选择。

这是一个自用、非商业的个人项目。它的设计依据来自反复使用和调整：减少一次多余操作，删掉一段不必要的说明，让功能之间衔接得自然一点。应用源码现已采用 GPL-3.0-only 公开，可按构建指南自行编译。[阅读完整的开发者碎碎念 →](DEVELOPER_NOTES.md)

## 禅怎样融入一天

| 此刻想做的事 | 在禅里的路径 | 接下来 |
| --- | --- | --- |
| 早晨，先完成一件小事 | 写下一项每日待办，从这项待办开始专注 | 任务留在本轮计时中；完成后自己打勾 |
| 工作中，只查一份资料 | 主动搜索需要的应用；如已设置提醒，先写下本次目标 | 按应用实际前台用时提醒，帮助想起原来的目的 |
| 阅读时，不想反复看手机 | 开始专注，按需开启“专注时简化桌面” | 暂停、继续和结束随时可用，到点后自己决定是否休息 |
| 晚上，看看一天的积累 | 打开专注统计，查看每日柱状图与周／月总时长 | 记录已经投入的时间，为明天安排留一点依据 |

**第一次打开，只选一项用就好。** 可以先体验计时，也可以先整理首页应用；不需要先建立完整计划、填写目标或开启全部权限。

## 功能围绕一件事展开

### 01 · 桌面保持安静，工具依然顺手

时间、天气、一句短文案和专注入口构成首页的主体。最多四个必要应用由你选择；开启折叠后，只留下底部的小标志，点击才展开。查找其他应用时，先输入名称，再显示结果，空搜索不推送推荐内容。

禅可以作为普通应用中的第二桌面，也可以接管默认桌面。设置里保留明确的返回原桌面入口，让尝试与退出都有路可走。

### 02 · 用适合自己的时长开始专注

轻点首页的专注图形或倒计时区域，就能开始或暂停；长按进入设置。专注与休息时长都支持自定义，点击数字旁的单位切换时、分、秒，范围为 **1 秒至 24 小时**。常用组合可以保存、修改和删除。

启动计时无需填写目标。也可以从一项待办开始，让这一轮专注有明确的事情可做；需要中断时，选择记录“下一步”，下次继续时更容易接上。到点提醒、休息和下一轮各有清晰的操作，计时不会自动连续循环。

### 03 · 待办、行动与记录连在一起

每日待办支持添加、勾选、删除与撤销，之前未完成的事项可以移到今天。完成一轮计时不会代替你勾选完成，任务是否做完仍由你判断。

需要跨应用提醒时，可开启“跨应用待办”，在其他应用上方保留今天的一项未完成事项。提示可展开、拖动或暂时隐藏；锁屏和全部完成时隐藏。它是可选功能，需要悬浮窗及通知权限。

专注统计用每日柱状图呈现累计，并提供每周、每月总时长，例如 `2h50min`。**只累计专注阶段实际运行的时间**；暂停、休息和应用目标用时不混入，提前结束仍保留已经运行的部分。

### 04 · 需要提醒时，帮你想起打开应用的目的

“首页应用”和“提醒应用”是两份独立名单。你可以让通信工具直接打开，只为容易忘记时间的应用设置目标提醒。

从禅打开提醒名单中的应用时，填写本次目的与提醒时间；之后按实际前台使用时间累计，切换应用或锁屏会暂停。提醒出现后可以返回禅，也可以继续使用并延后提醒，延后间隔可自定义。不同应用各自保留目标和用时。

重点通知则让你选择哪些应用的通知出现在禅内。**这项筛选仅作用于禅的展示**，不会代替系统关闭其他应用的通知权限。[两类计时与通知范围说明 →](docs/USER_GUIDE.md#应用提醒与重点通知)

### 05 · 让背景、天气和文字适应当下

六个内置主题提供不同的色调与场景：**水静、松风、晨曦、暮山、月白、夜泊**。背景与控件保持统一，昼夜可自动或手动切换；动态可关闭，省电模式下会暂停背景动画。

天气可在授权定位后自动获取，也可手动选城市。文案可按主题、白天／夜晚、天气与风景／专注／休息分类查看，支持添加、编辑、删除与恢复。轻点首页短句换一句，长按查看出处。

本次安装包和发布附件仅提供六个内置主题，**不发布外部主题卡**。[主题与文案使用说明 →](docs/THEMES.md)

## 我们在意的设计原则

| 原则 | 在产品中的取舍 |
| --- | --- |
| 减少主动出现的干扰 | 应用通过搜索找到，次要功能收起，没有空搜索推荐 |
| 让开始更简单 | 一键计时；目标只用于选定应用；权限按功能需要开启 |
| 提醒保持温和 | 展示原目标，允许继续使用，不用责备或强制锁定来要求专注 |
| 操作有前后衔接 | 待办可以开始专注，下一步可以留待继续，默认桌面可以退出 |
| 把记录的含义说清楚 | 专注时长代表计时器运行时间，不代表效率评分或持续注意力 |

## 安装与更新

**系统要求：Android 10 及以上。当前公开版本：0.5.8-diagnostic（约 22.2 MiB）。**

1. 从 [官方 Release](https://github.com/fwfeded/zen/releases/latest) 下载 `zen-33.apk`。源码压缩包不能直接安装；自行编译请从当前仓库获取源码，见 [构建指南](BUILDING.md)。
2. 按 Android 提示安装，先以普通应用体验。已有同签名版本时可直接覆盖，避免先卸载而丢失本地记录。
3. 想替换主桌面时，进入 **设置 → 桌面与退出 → 启用禅作为默认桌面**，由系统确认。

需要换回原桌面时，在同一页面选择 **退出并返回「原桌面名称」**。其他桌面的名称会因手机而异。[第一次使用与退出指引 →](docs/GETTING_STARTED.md)

后续进入 **设置 → 版本更新**。0.5.5 已预设更新入口；返回禅时最多每 24 小时自动检查一次。**下载由你点击，安装由 Android 确认**，不会静默安装或弹窗打断专注。

## 数据、兼容性与验证

待办、目标、专注记录、设置与自定义文案保存在本机。应用无需账号，没有云同步、广告 SDK 或分析 SDK。天气请求会向天气服务发送查询位置，更新请求会访问 GitHub；联网范围见 [隐私说明](PRIVACY.md)。

当前提供 **0.5.8-diagnostic 诊断版**，修复权限缺失时的启动流程并增加本地提醒诊断。165 项单元测试、14 项设备测试及模拟器进程退出后的计时恢复通过。**红米、一加的无声／无振动问题仍在调查，尚未宣告修复。** [验证与复测步骤](docs/RELEASE_0.5.8-diagnostic.md)。

<details>
<summary>使用前值得了解的当前限制</summary>

- 天气使用 Open-Meteo，与厂商自带天气可能不同；城市名识别、定位和刷新受设备服务及网络影响。
- 应用目标计时依赖使用情况访问；分屏与画中画的归属尚不保证准确。系统强行停止后需重新打开禅。
- 到点提醒受通知权限、通知通道、准点提醒及系统限制影响。
- 省电模式减少禅自身的动画与部分刷新；目前没有整机续航提升的对照结论。
- 当前没有云同步或完整导出恢复；卸载、清除数据会删除本地记录。
- GitHub 下载速度与可达性随网络变化。电脑端曾遇到超时，模拟器端实际下载与升级已通过。

[常见问题与排查方法](docs/FAQ.md)

</details>
