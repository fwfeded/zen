## 为有目的地拿起手机

禅可以作为第二桌面，也可以设为默认桌面。首页只保留时间、天气、一句短文案和专注入口；最多四个必要应用由你选择，也可以折叠到页面底部。其他应用通过主动搜索找到，空搜索不推荐内容。

功能需要时展开，完成后回到安静的桌面。

## 开发者的碎碎念

手机已经慢慢成为很多人——包括我自己——的第二故乡。可每天涌来的信息、越装越多的应用，也在不断占用我的注意力和时间。

所以，我想做一个第二桌面，帮我把自己的时间和注意力一点点拿回来。需要的应用依然能找到，只是不再每次拿起手机，都先被一整屏的内容拉走。

禅首先是做给自己用的。它不保证让我更自律，也不替我决定该做什么。我希望它能让拿起手机的那一刻更安静一点，让“现在要做什么”由我自己来选。

[继续读：为什么做禅](DEVELOPER_NOTES.md)

## 能做什么

| 想做什么 | 禅如何帮助你 |
| --- | --- |
| 开始一段专注 | 一键开始；专注与休息时长可自定义，单个输入框切换时／分／秒 |
| 记下今天的事 | 添加、勾选每日待办；可从一项待办开始专注 |
| 看见时间的积累 | 按天查看专注柱状图，汇总每周、每月；只统计专注计时实际运行时长 |
| 避免忘记打开应用的目的 | 仅对你指定的应用询问目标，按实际前台使用时间提醒 |
| 减少通知干扰 | 禅内仅展示重点应用通知；系统通知栏保持原样 |
| 留下一点个人风格 | 六个内置主题、昼夜和天气变化；可管理不同情境的文案 |

待办悬浮提示、应用目标提醒等功能按需开启，不要求先完成整套配置才能开始使用。

## 安装与第一次使用

1. 在 [Releases](https://github.com/fwfeded/zen/releases/latest) 下载 `zen-30.apk`（0.5.5，约 22.1 MiB）。GitHub 自动生成的 **Source code** 压缩包是仓库资料，不能安装到手机。
2. 打开 APK，按 Android 提示安装。已有同签名版本时直接覆盖安装，保留本地记录。
3. 先以普通应用体验，再决定是否设为默认桌面。权限只在使用相应功能时开启。

**换回原桌面：设置 → 桌面与退出 → 退出并返回原桌面。** 不需要以卸载作为正常退出方式。完整步骤见 [使用指南](docs/GETTING_STARTED.md)。

## 后续更新留在应用里

进入 **设置 → 版本更新**。返回禅时最多每 24 小时自动检查一次；新版本在设置中提示。下载需点击，安装由系统确认，不会自动弹窗打断专注。

0.5.5 已预设更新地址。0.5.4 等旧版可首次填入：

```text
https://github.com/fwfeded/zen/releases/latest/download/latest.json
```

更新前会核验包名、递增版本、文件大小、SHA-256 和签名。[更新与安装校验](docs/UPDATES.md) · [更新记录](CHANGELOG.md)

## 数据和权限说清楚

待办、目标、专注记录、设置和自定义文案保存在手机本地，没有账号或云同步，不接入广告和分析 SDK。

联网主要用于天气和版本更新。天气服务会接收查询位置，GitHub 会接收下载请求；因此“记录留在本机”不等于“应用完全不联网”。[隐私说明](PRIVACY.md) · [权限用途](docs/PERMISSIONS.md)

## 当前边界

- 这是个人测试项目。已进行 Android 15 模拟器验证，ColorOS 等真机仍需持续验收，不承诺所有机型表现一致。
- 天气来自 Open-Meteo，不读取手机厂商的私有天气数据库。定位、城市名称与更新及时性受系统服务和网络影响。
- 应用目标计时依赖使用情况访问；分屏和画中画下的时间归属尚不保证准确。系统强行停止应用后需重新打开。
- 专注时长是计时记录，不是对注意力或效率的测量；没有已验证的整机续航提升结论。
- **本次不发布任何外部主题卡。** APK 仅含最初六个内置主题，没有额外主题下载包。
