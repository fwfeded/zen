# 禅 · Zen

帮助减少无意识切换的 Android 极简桌面：保留必要应用，把专注计时、每日待办和专注统计放在需要时才能展开的位置。

## 版本更新

正式版本将通过本仓库的 [Releases](https://github.com/fwfeded/zen/releases) 发布。目前正在准备首次发布，尚无可用在线版本。

更新入口：`https://github.com/fwfeded/zen/releases/latest/download/latest.json`

在禅中进入 **设置 → 版本更新**。自动检查在返回桌面时触发，最多每 24 小时一次；发现新版本后由用户选择下载，再由 Android 确认安装。更新校验包名、递增版本、SHA-256 和签名，覆盖安装保留本地记录。

## 主题与数据

默认包含水静、松风、晨曦、暮山、月白、夜泊六个主题。额外主题通过用户自行导入的主题卡使用，本仓库不收录私人主题卡。

待办、专注记录和设置保存在手机本地；更新检查只读取版本清单，不上传这些数据。APK、版本清单与校验文件通过 Releases 分发，环境文件、设备备份、签名私钥和测试产物不会上传。

## 项目状态

Android 10 及以上的个人测试项目。此仓库先用于版本发布准备，后续整理源码、素材来源和开源许可证；现阶段不声明代码已经开源或附带任何特定许可证。
