# 常见问题

[返回首页](../README.md) · [完整使用手册](USER_GUIDE.md)

## 先按现象定位

| 遇到的问题 | 先检查什么 | 相关入口 |
| --- | --- | --- |
| 找不到想打开的应用 | 输入名称后才有搜索结果；首页最多四个入口 | 首页放大镜／设置 → 首页应用 |
| 到点没有提示 | 通知、计时通知通道、准点提醒、系统勿扰 | 设置 → 专注计时 → 到点提醒 |
| 天气没有城市名 | 定位与城市名识别是两个环节；可先手动选城 | 设置 → 天气 |
| 背景没有动画 | 动态开关、省电状态和专注状态 | 设置 → 主题／省电模式 |
| 编辑的短句没出现 | 当前主题、昼夜、天气、分类是否匹配 | 设置 → 文案设置 → 文案管理 |
| 修改时长后本轮没变化 | 新时长下一轮生效，当前计时保持 | 设置 → 专注计时 |
| 更新检查或下载失败 | 地址已保存、网络可访问 GitHub、安装来源许可 | 设置 → 版本更新 |

排查时保留错误文字、手机型号、系统版本及最短复现步骤。日志和截图去除个人信息后，再通过 [问题反馈](https://github.com/fwfeded/zen/issues/new/choose) 提交。

## 使用问题

### 必须替换默认桌面吗？

不必。可以先像普通应用一样打开禅，确认适合自己后再设为默认桌面。

### 怎样换回原桌面？

设置 → 桌面与退出 → 退出并返回「原桌面名称」。按钮以实际检测到的名称为准。禅会先尝试打开其他桌面再撤下自身桌面入口；没有检测到其他桌面时不会停用自己。厂商设置页空白时优先尝试此入口，并反馈型号、系统和路径。

### 天气为什么与手机自带天气不同，或显示“城市待识别”？

禅使用位置与 Open-Meteo 数据，不读取厂商天气私有数据库。城市名依赖 Android Geocoder；设备没有该服务或查询失败时，天气坐标可能已取得，但名称仍待识别。检查定位和网络，必要时手动选择城市。模型数据不保证每秒更新。

### 到点没有声音或振动怎么办？

先在“设置 → 专注计时 → 到点提醒”查看状态并点击“测试提醒”。0.5.7 修复了旧版默认静音配置；主动关闭过的通知、声音或振动设置不会被覆盖，可进入“声音与振动设置”调整。再检查通知音量、勿扰和准点提醒权限。分别测试前台和锁屏短计时；反馈时注明“测试提醒”和实际计时是否都无效。

### 专注累计代表什么？

只代表专注计时阶段实际运行的时间。暂停和休息不累计，提前结束保留已运行部分；应用目标用时单独计算，不重复合并。它不能证明你全程没有分心。

### 会隐藏系统通知，或者锁住我不让退出吗？

不会。重点通知筛选只作用于禅内展示；系统通知栏与系统退出方式由 Android 管理。禅帮助减少干扰，不把手机变成强制锁定设备。

### 省电模式一定让手机更省电吗？

尚无整机续航对照结论。降低动画和刷新频率可以减少禅自身的一部分工作，但屏幕亮度、其他应用和系统服务仍会耗电。不要仅凭极简界面推断电量改善。

### 更新后记录会保留吗？卸载后能恢复吗？

同包名、同签名覆盖安装按设计保留本地数据，已做模拟器数据保留验证。卸载、清除数据会删除记录；当前没有云同步或完整导出恢复功能。

### 我能下载更多主题卡吗？

本次只发布六个内置主题，不发布外部主题卡、主题卡合集或下载链接。应用保留本地导入能力，不等于本仓库提供额外资源。

### 支持哪些语言？

界面支持简体中文、繁体中文和英文，可以跟随系统；其他系统语言回退到英文。主题文案及用户编辑的内容不会自动翻译。

### 现在可以从源码构建吗？

可以。应用源码已按 GPL-3.0-only 公开，使用当前仓库并阅读 [构建指南](../BUILDING.md)。历史 v0.5.5 标签早于源码公开，只有当时的文档；Release 说明另提供完整源码固定提交。自编译包使用你自己的签名，不能直接覆盖不同签名的官方安装。详见 [项目状态](../PROJECT_STATUS.md)。
