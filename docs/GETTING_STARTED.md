# 开始使用禅

[返回首页](../README.md)

## 先作为普通应用体验

需要 Android 10 或以上系统。从 [官方 Releases](https://github.com/fwfeded/zen/releases/latest) 下载 APK，按系统提示安装。先打开体验，不必立即替换原桌面，也不必一次开启所有权限。

已安装禅时直接覆盖同签名版本。卸载或清除应用数据会删除本地记录，当前没有云同步或完整导出恢复功能。

## 把必要应用放在首页

在首页添加应用，最多保留四个。设置中可以开启应用栏折叠，轻点底部四点标志展开或收起。其他应用用右上角搜索查找，未输入时不展示推荐列表。

## 开始专注

点击首页专注图形／倒计时操作区开始或暂停，点击“调整时长”修改专注、休息时长。每项只有一个数字框，点击单位切换时、分、秒。也可以保存自己的常用预设。

首次需要后台到点提醒时，按界面引导开启通知和准点提醒权限。振动还受系统通知通道与手机设置影响。进入休息和下一轮均由你决定，不自动连续运行。

运行专注时默认简化桌面；需要其他功能时展开即可。专注统计只累计专注阶段实际运行时间，暂停、休息和应用目标用时不计入。提前结束仍保留已完成的专注时长。

## 每日待办与统计

首页图标可进入每日待办和专注统计。输入待办后可点加号或键盘“完成”；完成后打勾。待办可以关联一轮专注，计时结束不会自动把任务标为完成。

统计可以按周或月查看，每天有独立柱状展示。跨午夜的专注分到对应日期，不把一次长计时全部放在开始那天。

## 按需开启的功能

| 功能 | 操作 |
| --- | --- |
| 应用目标提醒 | 在设置中选定提醒应用；从禅进入时填写本次目标，再开启实际使用计时所需权限 |
| 所在地天气 | 开启手机定位，允许位置权限；失败时可用手动城市作为备用 |
| 重点通知 | 选择重点应用并开启通知使用权，仅改变禅内展示 |
| 待办悬浮提示 | 选定待办并允许悬浮窗，跨应用显示；可收起或关闭 |
| 主题与文案 | 选择六个内置主题；在文案管理中按情境查看、增删或编辑 |
| 界面语言 | 跟随系统，或选择简体中文、繁体中文、English；其他系统语言回退到英文 |

详细说明：[权限用途](PERMISSIONS.md) · [隐私](../PRIVACY.md)

## 设置为默认桌面与退出

确认体验后，可在 **设置 → 桌面与退出** 中启用禅作为默认桌面。

想切回去时，先使用同一页面中的 **退出并返回原桌面**。禅会尝试打开检测到的其他桌面，并撤下自己的默认桌面入口；普通应用入口和本地数据保留。重新接管默认桌面需要主动启用。

如果没有检测到其他桌面，禅不会停用自己的入口。若系统设置页空白或厂商 ROM 行为异常，请保留可用桌面并反馈手机型号、系统版本和操作路径，不要反复卸载重装作为排查起点。
