# 第一次使用禅

[首页](../README.md) · [完整手册](USER_GUIDE.md) · [常见问题](FAQ.md)

从一次简单的使用开始：安装、留下一两个常用应用，然后开始一段专注。默认桌面、应用提醒和其他权限都可以稍后再决定。

## 1. 下载并打开

系统需要 Android 10 或以上。在 [官方 Releases](https://github.com/fwfeded/zen/releases/latest) 下载当前版本的 **APK**，0.5.5 对应 `zen-30.apk`，约 22.1 MiB。不要下载 GitHub 自动生成的 Source code 压缩包来安装。

打开文件后按 Android 提示安装；系统可能要求为浏览器或文件管理器允许此安装来源。已经装过禅的用户，直接用同签名版本覆盖安装即可，不要先卸载。

第一次打开时，禅可以像普通应用一样运行。现在无需接管默认桌面，也无需一次开启所有权限。

## 2. 留下必要应用

轻点右上角省略号进入 **设置 → 首页应用**，选最多四个随手需要的应用，例如电话、短信或你常用的工具。其他应用通过首页放大镜搜索，输入名称后才显示结果。

如果希望首页更安静，在首页应用设置里开启折叠，底部的小标志就成为展开与收起入口。首页名单可以随时调整。

## 3. 开始第一次专注

轻点首页专注图形或倒计时区域即可开始；再点可暂停、继续。无需填写目标。

想先调整时长，长按该区域，或进入 **设置 → 专注计时**。填写专注与休息数值，点单位切换时／分／秒，然后开始。常用组合可以保存为预设。

需要后台或锁屏到点提醒时，展开计时面板中的提醒设置，按提示开启通知与准点提醒。初次可以用较短时长试一次，确认手机能收到提示；振动和声音受系统设置影响。

## 4. 给这一段时间一件具体的事

打开右上角待办图标，写下一项可执行的事情，例如“整理第二章笔记”，点加号或键盘完成键添加。可以从这项待办开始专注。

做完后手动打勾。计时结束不会自动完成任务；已经运行的专注时间会进入统计，提前结束也保留。首页统计图标可查看每日、每周、每月的累计。

## 替换主桌面与换回原桌面

体验合适后，进入 **设置 → 桌面与退出 → 启用禅作为默认桌面**，再由系统确认。之后返回主屏幕会进入禅。

想恢复原桌面，在同一页面点击 **退出并返回「原桌面名称」**。按钮会显示实际检测到的桌面名称。禅会尝试打开所选桌面并撤下自身默认桌面入口；普通应用入口和本地记录保留，需要时仍能打开禅。

如果没有检测到其他桌面，禅不会停用自己。部分厂商的系统默认桌面设置可能显示空白，优先使用禅内的直接退出入口，并反馈手机型号与系统版本。常规切换不需要卸载。

## 按需要再开启

| 想获得的体验 | 下一步 |
| --- | --- |
| 显示所在地天气 | 首页天气区域 → 开启定位天气；无法定位时使用手动城市 |
| 为特定应用设置目标提醒 | 设置 → 应用提醒 → 提醒应用 |
| 只在禅内看到重要通知 | 设置 → 重点通知 |
| 跨应用保留一项待办提示 | 每日待办 → 跨应用待办 |
| 换主题、调整昼夜与动态 | 设置 → 主题 |
| 换短句或编辑自己的文案 | 设置 → 文案设置 → 文案管理 |
| 跟随系统语言或手动切换 | 设置 → 语言 / Language |
| 获取下个版本 | 设置 → 版本更新 |

每项功能只开启它需要的权限。暂时不用的功能可以保持关闭。[权限用途](PERMISSIONS.md)

## 保留记录与后续更新

0.5.5 已内置更新地址，在版本更新页检查、下载，由 Android 确认覆盖安装。旧版首次配置步骤见 [更新指南](UPDATES.md)。

待办、专注记录和设置在本机保存，目前没有云同步或完整导出恢复。**卸载、清除应用数据会删除这些记录**；更换桌面和正常覆盖更新无需清除数据。

至此已经可以日常使用。需要进一步配置时，再查阅 [完整手册](USER_GUIDE.md)；遇到提醒、定位或安装问题，查看 [常见问题](FAQ.md)。
