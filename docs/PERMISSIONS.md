# 权限按功能开启

[返回首页](../README.md) · [隐私说明](../PRIVACY.md)

权限用于对应功能。拒绝某项权限不应阻止使用其余基础桌面功能。

| 权限或系统授权 | 用途 | 未开启时 |
| --- | --- | --- |
| 通知 | 专注到点提醒、应用目标提醒和可停止的运行状态通知 | 前台仍可查看计时；后台通知受限 |
| 闹钟和提醒 | 安排后台准点提醒 | 后台提醒可能延迟 |
| 使用情况访问 | 判断目标应用何时在前台，切出或锁屏时暂停累计 | 无法按实际前台使用时间提醒 |
| 通知使用权 | 读取当前通知并在禅内筛选重点应用 | 禅内重点通知列表不可用；系统通知栏不受影响 |
| 大致位置 | 获取所在地天气，坐标约化到小数点后两位后用于查询 | 可用手动城市 |
| 精确位置 | 无合适网络定位服务时，按提示使用 GPS 等定位途径 | 大致定位可用时无需额外开启；定位成功后仍约化查询坐标 |
| 显示在其他应用上层 | 跨应用显示可收起的待办提示 | 待办仍可在禅内使用 |
| 安装未知应用 | 用户点击“安装更新”后打开系统覆盖安装流程 | 可以检查新版；安装需先允许来源 |
| 前台服务 | 运行中的应用提醒、待办悬浮提示 | 相应功能不能持续运行；不用于全天轮询更新 |
| 开机与应用更新广播 | 恢复和核对本地提醒状态 | 由 Android 管理，无独立授权开关 |

应用还声明网络与振动权限。当前不申请读取通讯录、短信内容、通话记录、日历或录音权限；电话和短信入口用于打开系统应用。

厂商系统可能有额外的后台限制。只有遇到具体问题时才按界面提示检查相应设置；不建议一开始就关闭所有系统省电限制。
