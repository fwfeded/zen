# 0.5.8-diagnostic 验证与复测

2026-10-03；Android 10+；versionCode 33。与已交付诊断包为同一 APK，未重新编译。此诊断版按用户要求进入 Latest 应用内更新通道；不是声振问题已经解决的声明。

## 已验证

- 通知未授权的真实启动回归：旧代码失败（预期 idle，实际 running），修复后通过。
- 4 项权限界面测试：缺少通知、明确选择仅前台、待办入口、缺少精确计时权限。
- 10 项已有计时通知设备回归：前台专注和休息、后台、息屏、重复结算及测试入口。
- 165 项单元测试通过；Debug/Release 构建通过。
- 隔离 Android 15 模拟器终止应用进程后，30 秒到点重新唤醒、提交完成通知并累计 30000ms。
- 最终 Release APK 覆盖安装与诊断界面打开、复制按钮点击冒烟通过。
- 模拟器通知与配置验证不能代表实体机声音和震感已经正常。

## 手机复测

1. 应用内检查更新，安装 0.5.8-diagnostic，无需卸载。
2. 设置 → 专注计时 → 到点提醒 → 测试提醒。
3. 提醒诊断 → 复制诊断信息，将信息连同实际有无声音/振动反馈。
4. 再测试切到其他应用和锁屏的短计时。区分“没有顶部横幅”和“下拉通知栏也完全没有通知”；返回禅后再次复制诊断。

诊断只保存本地事件和必要系统状态，不包含待办、位置或其他应用通知，不自动上传。

## 未完成与版本边界

- 多台一加/红米无声无振的具体系统原因尚需真机诊断确认。
- 尚未加入独立闹钟音量铃声机制，其静音行为等待用户选择。
- 本地测试源码、测试记录、设备日志、环境、密钥和外部主题卡不在本次公开范围。
- 后续正式更新应使用 versionCode 34 或更高，使本诊断版也能直接更新。
