# 禅使用手册

[首页](../README.md) · [第一次使用](GETTING_STARTED.md) · [常见问题](FAQ.md)

适用于 0.5.8-diagnostic。下文采用简体中文界面名称；系统授权页由 Android 或手机厂商提供，名称与位置可能不同。

## 先认识首页

| 位置／入口 | 轻点后的用途 | 进一步操作 |
| --- | --- | --- |
| 右上角待办图标 | 每日待办 | 添加、勾选、查看此前事项，从任务开始专注 |
| 右上角统计图标 | 专注统计 | 切换周／月，查看每天与整段时间的累计 |
| 右上角放大镜 | 查找应用 | 输入名称后查看匹配结果 |
| 右上角省略号 | 设置 | 应用、计时、主题、天气、文案、语言、更新等 |
| 天气区域 | 天气设置 | 开启所在地天气或使用手动城市 |
| 首页短句 | 切换文案 | 长按查看出处；详细编辑在文案设置中 |
| 专注图形与倒计时区域 | 开始、暂停或继续 | 长按展开专注计时面板 |
| 底部四点标志（折叠开启时） | 展开／收起首页应用 | 在首页应用设置中配置 |

面板顶部的返回箭头回到上一级，“关闭”回到桌面。长列表可在面板内滚动；文案管理的筛选区固定在列表上方。

## 整理首页应用

进入 **设置 → 首页应用**，选择真正需要随手打开的应用，最多四个。首页名单只决定哪些入口常驻，不等同于提醒名单或重点通知名单。

需要更清爽的桌面时开启应用栏折叠。底部保留小标志，轻点展开，再点收起。没有放到首页的应用仍可通过查找使用；从首页移除不等于卸载。

建议先保留最常用的通信或工具应用，再观察实际需要，而不必一次填满四个位置。

## 专注计时：从开始到下一轮

### 直接开始

轻点首页专注操作区即可开始，不必输入目的或选择任务。再次轻点可暂停、继续。要查看完整控制，长按该区域，或进入 **设置 → 专注计时**。

开启“专注时简化桌面”后，运行期间会减少首页展示；这不会阻止你使用手机其他功能。

### 调整时长与常用预设

1. 打开专注计时面板。
2. 在专注、休息两个输入项中填写数字，点击旁边的单位切换 **时／分／秒**。每项支持 1 秒至 24 小时。
3. 要直接进入下一轮，使用主操作按钮；要只保存设置，点击出现的“保存时长”。
4. 经常使用的组合可“保存为预设”。“常用预设 → 管理”中可以修改或删除，删除后可在当前界面撤销。

**保存时长**改变后续计时的设置；**保存为预设**将这个组合加入可重复选择的列表。正在运行或暂停的一轮不会因修改设置被重新计时，新时长在下一轮生效。

切换单位会将当前数字按新单位解释，而非做等值换算。例如 `25 分` 切换为 `秒` 后表示 `25 秒`，不是 `1500 秒`。保存或开始前，请一起核对数字和单位。

### 提醒、休息与结束

展开“到点提醒”，查看当前声音／振动状态，按需要开启通知和准点提醒；“声音与振动设置”进入对应系统设置。“测试提醒”使用与计时结束相同的通知渠道，不会启动计时或增加统计。“提醒诊断”可查看和复制本地调度与通知配置信息，不自动上传。缺少通知或精确计时权限时，开始前会提供设置入口；继续受限计时需明确选择。声音和振动受手机通知通道、通知音量、勿扰及系统限制影响。

专注到点后，可手动开始休息；休息结束后，可手动开始下一轮。要提前停止，选择“结束本轮”。已经累计的专注时长保留，结束计时不会自动将关联待办打勾。

## 每日待办：让计时对应一件具体的事

打开首页待办图标，输入一项事情，点加号或键盘完成键添加。单项最多 80 字，适合写成一个可执行的动作，例如“整理第二章笔记”。

- **完成与恢复未完成：** 点任务左侧勾选框；完成文字划线，再次点击可取消完成。
- **开始专注：** 点未完成事项旁的专注操作。若已有计时，按界面当前状态选择继续或处理已有的一轮。
- **留住上下文：** 在关联任务的计时面板中选择“记录下一步（可选）”；之后可“继续上次待办”。
- **查看旧任务：** 用“前一天／后一天”查看已到达的日期；今天页面的“之前未完成”可展开，并将旧事项“移到今天”。
- **删除与撤销：** 使用任务右侧删除入口，误删后可在当前界面撤销。

计时到点只是这一段时间结束，是否完成任务由你判断。

### 跨应用待办

每日待办面板顶部可开启“跨应用待办”。按提示允许悬浮与通知权限后，会显示今天的一项未完成待办。

点击提示展开操作，拖动调整位置；阅读时可使用收起或暂时隐藏，让提示少遮挡内容。暂时隐藏后，可回到每日待办点“恢复显示”。不再需要时关闭开关。锁屏、全部完成时提示隐藏；部分系统安全页面不允许悬浮层覆盖。

## 专注统计：每一段时间怎样累计

从首页统计图标或 **设置 → 专注统计** 进入。选择周或月，查看每日柱状图和总时长；周以周一开始。展示采用 `50min`、`2h50min` 等紧凑格式，不足一分钟会显示 `<1min`。

| 情况 | 是否计入专注累计 |
| --- | --- |
| 专注阶段运行 | 计入实际运行部分 |
| 暂停计时 | 不计入暂停期间 |
| 提前结束 | 已运行部分仍保留 |
| 休息阶段 | 不计入 |
| 应用目标提醒的前台用时 | 独立记录，不并入 |
| 跨午夜的一段专注 | 分配到对应日期 |

这些数据反映的是计时记录。禅不检测你是否真正投入，也不据此给你打分。

## 应用提醒与重点通知

### 只对指定应用询问目标

进入 **设置 → 应用提醒 → 提醒应用** 选择名单。从禅打开这些应用时填写本次目标与提醒时间；其他应用直接打开。可以只给一两个容易忘记时间的应用开启。

例如，你想在视频应用查一道题的讲解，可以写下“找到这道题的解法”。提醒时原目标会再次出现，帮助判断接下来是继续查找，还是返回禅。

实际前台用时需要“使用情况访问”等相关授权。切换到其他应用、锁屏时暂停；权限不足时不会用简单的经过时间冒充实际使用时间。分屏或画中画归属尚不保证精确。通过其他入口启动应用的行为不应视为受到完整拦截。

“进行中的目标”可查看各应用记录。继续使用后的延后间隔可在应用提醒页自定义；这里的“提醒时振动”与专注计时的系统通知通道分别设置。

### 只让重要通知出现在禅里

进入 **设置 → 重点通知**，按引导开启通知使用权并选择重点应用。这个设置控制禅内通知展示，不会代替系统取消或关闭其他应用的通知。

若要整理整个手机的通知，使用该功能提供的系统设置入口逐项调整。系统授权仍由你确认，禅不提供静默批量关闭权限的能力。

## 天气、主题与界面语言

**天气：** 轻点首页天气区域或进入设置中的天气。允许定位后自动获取所在地天气；城市识别或定位不可用时可改用手动城市。来源为 Open-Meteo，可能与系统天气不同。

**主题与文案：** 在主题页选择背景与日夜模式；文案分类、编辑与恢复位于 **设置 → 文案设置**。详细步骤见 [主题与文案](THEMES.md)。

**语言：** 进入 **设置 → 语言 / Language**，选择跟随系统、简体中文、繁体中文或英文。其他系统语言回退英文；你的待办、目标和自定义文案不会被自动翻译。

**省电：** 设置中的省电模式暂停背景动画，并降低自动定位频率；计时与提醒继续。应用也会跟随系统省电状态。目前没有整机续航对照测试结论。

## 默认桌面、更新与数据

- 默认桌面的启用与恢复位于 **设置 → 桌面与退出**，操作见 [开始使用](GETTING_STARTED.md#替换主桌面与换回原桌面)。
- 更新位于 **设置 → 版本更新**，检查、下载、系统确认安装分开进行，见 [更新指南](UPDATES.md)。
- **设置 → 权限与数据** 可查看权限及清除入口。“清除专注记录”与“清除全部本地数据”影响范围不同，操作前阅读确认内容。

当前没有云同步或完整数据导出恢复；卸载与系统清除数据会删除记录。常规升级请使用同签名覆盖安装。[数据范围](../PRIVACY.md) · [问题排查](FAQ.md)

## 0.5.6：图标大小与文案语言

在“设置 → 首页应用”选择小、中、大，可即时预览并保存首页图标大小；默认中号。背景动画开关不再关闭底部栏的旋转反馈。系统关闭动画时，四点直接切换到展开形态。

内置文案随简体、繁体、英文切换，各语言的编辑分别保存。旧简体修改仍保留；主题卡保留作者原文。
